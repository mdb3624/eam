# Definition of Ready (DoR)

A User Story is "Ready" for a Sprint only if it meets these criteria:

- **Clarity:** The "As a/I want/So that" statement is defined.
- **Acceptance Criteria:** At least 3-5 measurable test cases are listed.
- **Field Contract Table (if this project uses one):** Scope flag is set and all sign-offs required by that Scope are checked.
- **Technical Specs:** The Solution Architect has confirmed the schema/design impact.
- **Estimation:** The story has been pointed/sized by whoever is implementing it.
